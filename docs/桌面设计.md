# Deshab 桌面设计文档

> desktop.elf（Winux-Kate结构）的页面、应用、视觉、渲染与性能设计。事实以`CODE/desktop/main.c`与`CODE/UTSM/include/utsm/deshab_ui.h`为准。

---

## 1. 概述

`desktop.elf`是B4锚点加载的桌面管理器，全屏独占framebuffer，复刻Winux-Kate布局。直接轮询PS/2键盘/鼠标，通过boot context获取内核服务，EXIT返回DSK。

Kate之外的桌面特性：RTC+UP计时；VOL/BRIGHT可拖滑块（BRIGHT真实调暗）；开机打字机Boot屏；FILES双击载入EDITOR（FAT32读写+SAVE）；窗口单实例聚焦；Linux应用图标集成（LINUXAPP.CNF→兼容层委托执行）。

---

## 2. 整体布局

```text
app-shell
├── topbar (34px)：品牌+工作区切换+页面切换+PG时钟
├── page-host
│   ├── 1·DASHBOARD：TERM-01/TERM-02/EDITOR/FILES四面板+StatusBar(32px)
│   ├── 2·IDE：标签栏+编辑宿主
│   ├── 3·DESKTOP：图标网格+窗口+顶栏/Dock（Aqua，§12；KATE 回退为任务栏）
│   └── 4+/CUSTOM：外部.elf全屏宿主(≤4页，可增删)
└── task-view overlay（工作区卡片）
```

布局常量：KATE_TOPBAR_H=34, KATE_STATUSBAR_H=32, KATE_PAGE_PAD=8, 图标104×90, 网格gap=18, pad=24。

## 4. 应用机制（app_descriptor）

所有应用以`app_descriptor`注册（MAX_APPS=16 = 6内置+≤8 Linux应用+余量）：

```c
typedef struct {
    const char *name, *display_name;
    u32 default_w, default_h;
    app_create_fn  on_create;    // 内置应用
    app_event_fn   on_event;
    app_draw_fn    on_draw;
    app_destroy_fn on_destroy;
    const char *elf_name;        // 外部ELF全屏宿主(8.3名)
    const char *linux_cmd;       // Linux兼容层命令
} app_descriptor;
```

`elf_name`与`linux_cmd`互斥（elf_name优先）；仅设linux_cmd时须提供on_create（内置终端窗口承载）。

内置应用：shell(SHELL.ELF)、cmd(CMD.ELF)、editor(内置)、fileman(FILEMAN.ELF)、calc(内置)、browser(BROWSER.ELF)。

单实例策略：固定地址ADDR_TERM1=0x4000000/ADDR_TERM2=0x4100000/ADDR_TERMWIN=0x4200000/ADDR_EDDASH=0x5000000/ADDR_EDWIN=0x5100000/ADDR_CALC=0x6000000。

独立工具应用共享`CODE/tools/desktop_app.h`：dsk_entry入口+da_app_context(fb+block read/write+kernel_api)，block API从kernel_api+0xA8取(read@+0x10,write@+0x18)。

## 5. 视觉系统

### 5.1 "Sealed Arc"设计语言

三隐喻：Arc(弧)——圆角/弧形边框；Seal(封)——卡片容器/发光边缘；Flow(流)——渐变/平滑过渡。

### 5.2 设计令牌

| 层 | 内容 |
|----|------|
| L0 原始色板 | Abyss Blue(900–100九级)/Seal Cyan(主操作)/Arc Violet(次级)/Neutral 0–900/语义色/渐变三色 |
| L1 语义色值 | 暗色主题(Shell: BG=DP_ABYSS_900, 主文字=DP_NEUTRAL_700, 强调=DP_SEAL_500)；亮色(FirstInit/DSK) |
| L2 组件令牌 | 圆角/高度/内边距/边框，引用L1 |

约定：色值0xAARRGGBB；**所有UI组件必须经deshab_ui.h取参数，禁止硬编码**。

### 5.3 落地决策

- DU_RADIUS_MD/LG改为0(直角)，仅小按钮4px/模态框16px/药丸全圆角
- 简化面板渲染/窗口光晕/不必要渐变；hover提亮，active反转色

## 6. 渲染架构

### 6.1 双缓冲

渲染到sprite buffer(SPRITE_BUF_ADDR=0x7000000, 112MB, identity-mapped)，完成后flip到真实framebuffer。flip_buffer()全屏拷贝；flip_rect(x,y,w,h)仅拷贝指定矩形。

### 6.2 脏矩形

MAX_DIRTY_RECTS=16，mark_dirty记录变化区域，溢出降级全屏重绘。每帧合并为包围盒→redraw_all+flip_rect(合并区域)。终端面板有行级脏标记(dirty_rows+any_dirty)。

### 6.3 光标

软光标24×24，移动时save/restore背景+两次局部flip_rect(旧位置+新位置)。动画延时期间持续轮询鼠标。

### 6.4 主循环

```text
轮询PS/2鼠标→滑块拖拽→排空键盘缓冲→handle_key→RTC tick→
  need_redraw? 全屏重绘+flip / 脏矩形→redraw_all+flip_rect(包围盒)
  moved? 光标save/restore+局部flip
```

## 8. 桌面图标来源（.lnk快捷方式 + LINUXAPP.CNF Linux应用）

### 8.1 .lnk快捷方式

`setup_desktop_icons()`先上架4个用户快捷方式（编辑器/文件管理/浏览器/终端），`shortcuts_refresh()`当前为硬编码列表（SYSTEM/user/desktop/*.lnk已随镜像分发，解析留待后续）；快捷方式图标`app_id=-1`，双击经`launch_external_elf()`加载对应工具ELF全屏宿主。

### 8.2 LINUXAPP.CNF Linux应用

快捷方式之后追加Linux应用图标。**无论Linux兼容层服务是否可用都注册**：桌面启动时读FAT32根目录LINUXAPP.CNF(8.3名LINUXAPPCNF)，每行一条：`显示名|linux命令`。规则：空行/#注释忽略；显示名≤11字符(DA_LINUXAPP_NAME_CAP=12)，命令≤63字符(DA_LINUXAPP_CMD_CAP=64)；按空格分词(首token为程序路径，绝对路径直接用，裸命令补/bin/前缀)；DA_LINUXAPP_MAX=8。CNF缺失/无有效行时回退内置默认3条（HELLO=/bin/echo、UNAME=/bin/uname -a、LS=/bin/ls -l /，均为Arch rootfs与initramfs busybox共有命令）。

- 图标：`draw_icon_linux`暗底终端+霓虹绿`>_`；服务不可用(VMX缺失/guest未驻留)时改用KS_TEXT_DIM置灰（`g_lnx_svc_up=0`）
- 双击：内置终端窗口承载（720×480，标题`NAME . Linux`）→回显`$ <cmd>`→`lnx_on_create`运行时复查服务：
  - 可用：`linux_compat_service.exec()`同步委托执行（UI冻结），输出经ANSI CSI剥离/`^M`忽略/`\t`展开一次性追加，`[exit N]`按退出码绿/琥珀
  - 不可用：红色提示`linux: compat service unavailable`+`[exit -1]`，绝不panic
- 串口打点：`linux apps: loaded LINUXAPP.CNF`/`builtin defaults`/`service unavailable (icons greyed)`、`linux app registered: <名>`、`linux exec`、`app launched`

## 9. 输入系统

- 事件模型：EV_MOUSE_MOVE/DOWN/UP, EV_KEY_DOWN/UP（坐标/按键/scancode/修饰态）

- 交互控件：窗口拖拽、任务栏项、VOL/BRIGHT滑块(slider_set拖拽)、亮度延迟应用

## 11. 动效与材质基础设施

`g_fluent=1`（FUCK `[desktop] fluent=`，缺省 1）时外壳是 macOS Aqua（§12），没有风格开关；`fluent=0` 是 KATE 回退路径（壁纸 / logo 缺失时的 `[panic] mode=fallback` 出口）。Aqua 窗口框按呈现矩形绘制，命中测试仍读逻辑矩形 `x/y/w/h`（交互时两者已吸附一致）。

| 函数 | 文件 | 约定 |
|------|------|------|
| `motion_bind` / `motion_spring_to` / `motion_ease_to` / `motion_px` | `CODE/desktop/motion.h` | 16.16 定点。弹簧刚度 26、每 16ms 速度保留 160。`motion_tick(dt)` 推进全部窗口轨道，`motion_step` 推进单条（Dock / Launchpad），dt 钳在 1..32ms |
| `desktop_motion_step` | `CODE/desktop/main.c` | 主循环与 PE pump 每帧调用：按 TSC 取 dt，更新顶栏 / Dock 指针目标，推进窗口 / Dock / Launchpad 轨道，再 `wm_anim_settle` |
| `win_present_sync` / `win_present_rect` / `win_present_animate_to` / `win_present_settled` | `CODE/desktop/wm.c` | 吸附 / 读出 / 弹簧追向逻辑矩形 / 全部轨道静止 |
| `glass_init` / `glass_pixels` / `du_glass_wallpaper` | `CODE/desktop/glass.h` | 壁纸半径 8 盒式模糊，结果在 `0x9100000`（上限 8MB） |
| `du_blit_scaled_alpha` | `CODE/desktop/blit.h` | 8.8 双线性 + src-over，alpha 0..256 |
| `aqua_*` | `CODE/desktop/aqua_draw.h` | 角区 4x4 超采样抗锯齿圆角填充 / 描边、多层投影、圆点、毛玻璃（模糊壁纸与当前像素按透视量混合再叠 tint）、弹出面板、线性图标任意尺寸版、应用图标缓存（96px 母版 + 48px mip，之后只做缩放 blit） |
| `g_aqua_theme` / `AQUA_*` | `CODE/desktop/aqua_theme.h` | 顶栏 24、Dock 图标 48→72、Dock 圆角 18、窗圆角 12、标题栏 28、红绿灯直径 12 间距 8 |

`[desktop] motion_selftest=1` 时启动串口打印 `[motion] settled` 与 `[glass] blur ok`。不画测试图形。

## 12. Aqua 外壳

重绘顺序（`compositor.c redraw_all_fluent`）：壁纸 → 桌面图标 / 窗口 → 调度中心 / 右键菜单 → 顶栏 → Launchpad → Dock → 下拉菜单 / 卡片 → 亮度 / 整蛊 / 光标。Launchpad 在 Dock 之下，打开时 Dock 仍可点击。

左键路由（`shell.c on_left_press`）：Launchpad（打开时恒消费，Dock 区域先交给 Dock）→ 卡片 → 顶栏 → Dock → 调度中心 / 右键菜单 → 窗口三钮 → 标题栏拖拽 → 客户区 → 桌面图标。悬停目标（`aqua_hover_key`）变化时才整屏重绘。

| 部件 | 文件 | 行为 |
|------|------|------|
| 顶栏 | `menubar.c` | 24px 毛玻璃。Apple 菜单：关于本机（需注册 `sysinfo`）、重新启动… / 关机…（弹关机确认卡片）；无睡眠（S3 未实现）。粗体聚焦应用名（菜单：退出）、窗口菜单（最小化 / 缩放 / 关闭窗口，无聚焦窗口时置灰）。右侧 Wi-Fi、控制中心、时钟"周四 11月19日 16:25" |
| 卡片 | `taskbar.c` | Wi-Fi（扫描 / 密码 / 连接）、控制中心（音量 / 亮度滑块）、关机确认（关机 / 重新启动 / 取消），从顶栏图标下方弹出 |
| Dock | `dock.c` | 底部居中，距底 6px。启动台、STARTMENU.CNF 前 8 项、未固定的运行中应用、分隔线、调度中心。每图标一条弹簧轨道 48→72px，按到基准中心的距离 smoothstep 衰减（半径 3 个图标），底对齐。4px 运行点、启动弹跳 12px / 6px、悬停名称气泡。点击：启动 / 聚焦 / 从最小化恢复 |
| Launchpad | `launchpad.c` | 全屏毛玻璃 + 深色 tint，搜索框，7 列 64px 网格 + 中文标签。打开 / 关闭 ease 180ms，网格 0.94→1 倍缩放。点空白 / Esc / Dock 启动台按钮关闭；F4 与串口 `3` 切换 |
| 窗口 | `wm.c` | 圆角 12、28px 标题栏、居中标题、左上红黄绿三钮（悬停显示 × − +，失焦变灰）、柔和投影。动画：打开 0.92 倍弹簧 + 160ms 淡入；关闭 160ms 收到 0.9 倍并淡出后 `win_destroy`；最小化弹簧飞向 Dock 图标并淡出；恢复反向；缩放在顶栏与 Dock 之间切换。动画期间只画框，不画应用内容 |
| 桌面图标 | `appreg.c` / `pages.c` | 右上角起一列向下排，满列左移；52px 圆角图标 + 白字带投影标签 |
